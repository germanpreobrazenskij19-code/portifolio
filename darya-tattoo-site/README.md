# Darya Tattoo Studio

Сайт студии Darya в Санкт-Петербурге.

## Запуск

```bash
npm run dev
```

Локальный адрес: http://127.0.0.1:4180

## Сборка

```bash
npm run build
```

Данные и цены сверены с публичной карточкой Darya на Яндекс Картах. Портфолио собрано из открытых галерей студии. Источники сохранены в `references/`.
