# Fionin Tattoo

Адаптивный статический сайт студии в Рязани. Первый экран использует предоставленное изображение татуировки; всё ниже пересобрано в компактную страницу: реальные работы, услуги, FAQ, подготовка записи и контакты.

## Запуск

Из папки проекта:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

Адрес: http://127.0.0.1:4174/. Сборка и установка зависимостей не нужны. Для статического хостинга используйте содержимое `dist`.

## Запись

Форма составляет сообщение из услуги, необязательного имени и описания идеи. Посетитель проверяет текст, копирует его и отправляет в VK. Время и цену подтверждает мастер в переписке. Сайт не хранит данные формы, не имитирует отправку заявки, CRM или оплату. Без JavaScript доступна прямая ссылка в VK, кнопка подготовки сообщения отключена.

## Содержание

- Адрес, контакты, услуги и рейтинг: https://yandex.com/maps/org/fionintattoo/133656900972/
- Время работы и этаж: https://2gis.ru/firm/70000001048501400
- Сообщество студии: https://vk.com/fionintattoo
- Данные проверены 12 сентября 2026. Стоимость и доступность мастеров уточняются при обращении.

В `references/portfolio-sources.json` указаны источники шести реальных фотографий. В сетке используется CSS-кадрирование, в галерее открывается целое фото. `dist/assets/hero-back-tattoo.png` — предоставленный пользователем визуальный референс для первого экрана. Вертикальное изображение показывается целиком без растягивания. `dist/assets/reference.png` — прежний макет, он больше не используется в херо. Прежние сгенерированные изображения нижних блоков удалены из публикации. История макетов сохранена отдельно в корневом `output/fionin-tattoo`.

Шрифты Bodoni Moda, Prata и Manrope хранятся локально. Внешние аналитика и шрифты не подключены. Карта открывается ссылкой на карточку студии.

## Проверка

- Херо и его стили сохранены; HTML блока проверен по SHA-256 до и после изменения.
- Нет горизонтальной прокрутки на ширинах 320, 390, 768 и 1440 пикселей.
- Проверены мобильное меню, выбор услуги, подготовка сообщения, раскрытие 3/6 работ, фильтры и просмотр фото, закрытие диалогов с Escape.
- Проверены ссылки на локальные файлы и якоря, синтаксис JavaScript и консоль браузера.
- Сообщения студии при проверке не отправлялись.
