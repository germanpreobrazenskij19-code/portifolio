# Fionin Tattoo

Адаптивный статический сайт студии в Рязани. Весь дизайн собран вокруг выбранного херо: песочная палитра, бордовые акценты, компактная закреплённая шапка, асимметричная галерея, услуги, FAQ, запись и контакты. Правила оформления — в DESIGN.md.

## Запуск

Из папки проекта:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

Адрес: http://127.0.0.1:4174/. Сборка и установка зависимостей не нужны. Для статического хостинга используйте содержимое `dist`.

## Запись

Форма составляет сообщение из услуги, необязательного имени и описания идеи. Посетитель проверяет текст, копирует его и отправляет в VK. Время и цену подтверждает мастер в переписке. Сайт не хранит данные формы, не имитирует отправку заявки, CRM или оплату. Без JavaScript доступна прямая ссылка в VK, кнопка подготовки сообщения отключена.

## Проверка

- Херо и его стили сохранены; HTML блока проверен по SHA-256 до и после изменения.
- Нет горизонтальной прокрутки на ширинах 320, 390, 768 и 1440 пикселей.
- Проверены мобильное меню, выбор услуги, подготовка сообщения, раскрытие 3/8 работ, фильтры и просмотр фото, закрытие диалогов с Escape.
- Проверены ссылки на локальные файлы и якоря, синтаксис JavaScript и консоль браузера.
- Сообщения студии при проверке не отправлялись.

## Публикация на Vercel

Публичный сайт: https://fionin-tattoo-site.vercel.app/
Проект: fionin-tattoo-site, аккаунт germanpreobrazenskij19-codes-projects. Опубликован 13 сентября 2026.

Из папки fionin-tattoo-site после входа в Vercel CLI:

```sh
npx vercel deploy --prod --yes --scope germanpreobrazenskij19-codes-projects
```

vercel.json публикует готовую папку dist без сборки и установки зависимостей. .vercelignore исключает служебные файлы, локальная привязка .vercel не коммитится.

Деплой выполнен напрямую через CLI. Автоматическое подключение репозитория portifolio к Vercel завершилось ошибкой доступа; автодеплой из GitHub не настроен. Обновления публикуются указанной командой. Синхронизация исходников с GitHub работает отдельно.

Проверено: публичные HTML, CSS, JavaScript и фотографии возвращают HTTP 200 и совпадают с локальными файлами; форма готовит сообщение с выбранной услугой.

Главная работа в портфолио — выбранный пользователем орнамент на спине с красным камнем. Использована версия того же снимка из карточки студии размером 905 × 1280, показанная целиком. Первая тройка: орнамент на спине, пирсинг уха, цветок на лопатке.
