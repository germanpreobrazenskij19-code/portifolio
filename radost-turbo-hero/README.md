# Радость — сайт тату-студии

Полная адаптивная одностраничная версия в направлении Turbo Tattoo. Первый экран с оригинальным видео из карточки, 6 работ с полноэкранной галереей, мастер, этапы, отзывы, FAQ и контакты. Запись ведёт непосредственно в Telegram мастера; формы и серверной обработки персональных данных нет.

## Запуск

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory /Users/retention/Documents/auto/output/radost-turbo-hero
```

Предпросмотр: http://127.0.0.1:8768/ . Сайт локальный, публикация не выполнялась.

Видео без звука, с зацикливанием и поддержкой reduced motion. Нижняя полоска героя с адресом, слоганом и паузой удалена по просьбе пользователя. Фото открываются в исходном соотношении сторон; в сетке используется кадрирование CSS, исходные изображения не изменены.

Галерея: кнопки назад/вперёд, стрелки клавиатуры, Escape для закрытия, нативное удержание фокуса dialog. Без JavaScript ссылка открывает исходный файл. FAQ работает без JavaScript. Навигация по разделам, ссылки телефона, Telegram, VK и карты действующие; сообщения не отправлялись.
